## Обзор

AIChat — Android-приложение для общения с ИИ-персонажами. Создайте персонажа с аватаром, именем и промптом, подключите собственный API, совместимый с OpenAI, и начинайте общение.

Поддерживаются OpenAI, Claude, DeepSeek, Volcengine (Doubao), Gemini, Qwen и Kimi, а также произвольные собственные эндпоинты. Чаты, аватары и вложения хранятся в выбранной вами папке — ничего не проходит через собственный сервер, а сообщения отправляются только настроенному поставщику API.

Приложение написано на Kotlin и Jetpack Compose (Material 3). Размер APK — около 1,4 МБ.

## Возможности

- **Несколько персонажей**: аватар, имя и промпт для каждого персонажа, используются как системный промпт
- **Профиль пользователя**: аватар, имя и промпт отправляются модели вместе с настройками персонажа
- **Пресеты поставщиков**: OpenAI / Claude / DeepSeek / Volcengine (Doubao) / Gemini / Qwen / Kimi; адрес и модели подставляются автоматически
- **Быстрый доступ к ключам**: значок ключа слева от поля API-ключа открывает страницу управления ключами поставщика
- **Потоковая передача**: отключается в «Настройки → Общие»
- **Анимация печатной машинки**: ответ появляется посимвольно; анимации капли и курсора можно включать отдельно
- **Управление сообщениями**: удаление кнопкой в строке под сообщением; долгое нажатие на пустое место рядом с сообщениями включает множественный выбор, долгое нажатие с перетаскиванием быстро добавляет сообщения, удаление — на нижней панели; долгое нажатие на текст по-прежнему выделяет слова
- **Ввод**: поле промпта использует плавающую метку, прокручивается внутри и имеет перетаскиваемую полосу прокрутки
- **Локальное хранение**: при первом запуске выберите папку; чаты, аватары, вложения и настройки хранятся в ней. Удаление приложения не удаляет папку; после переустановки выберите ту же папку
- **Языки и тема**: китайский / английский / немецкий / французский / японский / корейский / русский, светлая и тёмная темы следуют системе
- **Защита несохранённых изменений**: при выходе из изменённой формы приложение спросит, отменить или сохранить

## Скачать

Скачайте последний `AIChat-x.y.z.apk` из [Releases](https://github.com/SuXinxin520/AIChat/releases).

Требуется Android 8.0 (API 26) или новее.

> Начиная с 0.0.3 приложение использует официальный ключ подписи, отличный от старых сборок. Если установлена старая версия, сначала удалите её. Данные остаются в выбранной папке хранения; после переустановки выберите ту же папку.

## Использование

1. При первом запуске выберите локальную папку для данных (позже можно изменить в «Настройки → Хранилище»)
2. Откройте «Настройки → API», выберите поставщика или введите собственный эндпоинт и вставьте API-ключ; значок ключа слева от поля адреса открывает страницу ключей поставщика
3. Вернитесь на главный экран, добавьте или откройте персонажа и начните общение

## Данные и конфиденциальность

- Все настройки, чаты, аватары и вложения хранятся в выбранной папке; внутри приложения остаётся только небольшой кэш настроек
- Данные не отправляются на собственный сервер
- Сообщения отправляются только настроенному поставщику API
- Удаление приложения не удаляет папку хранения; после переустановки выберите ту же папку

## Сборка

Требования: JDK 17 и Android SDK 35.

```bash
./gradlew assembleRelease
```

APK создаётся в `app/build/outputs/apk/release/app-release.apk`. В release-сборке включён R8, размер около 1,4 МБ.

Данные подписи читаются из `keystore.properties` в корне проекта (файл исключён из git):

```properties
storeFile=/path/to/your/release.jks
storePassword=******
keyAlias=aichat
keyPassword=******
```

Без этого файла создаётся неподписанный release APK, чтобы вы могли настроить собственную подпись.
